## Efectos Interactivos

### 1. **Navbar**
```
Estado Normal:     [Menú] translúcido
Al hacer Scroll:   [Menú] más opaco con sombra
Hover en Link:     Subrayado naranja animado
```

### 2. **Botones**
```
Estado Normal:     Gradiente naranja
Hover:             Rotación de gradiente + elevación + sombra
Click:             Feedback visual
```

### 3. **Tarjetas de Producto**
```
Estado Normal:     Sombra suave
Hover:             Elevación + zoom de imagen + overlay oscuro
                   Botón "Ver" aparece con suavidad
```

### 4. **Cajas de Características**
```
Estado Normal:     Borde gris claro
Hover:             Borde naranja + elevación + sombra color naranja
```

### 5. **Links**
```
Estado Normal:     Naranja
Hover:             Naranja más claro + subrayado animado
```

## Transiciones

Todas las transiciones duran **0.3 segundos** con easing suave:
- Botones: Elevación + Sombra
- Links: Color + Subrayado
- Cards: Elevación + Sombra
- Icons: Rotación leve
